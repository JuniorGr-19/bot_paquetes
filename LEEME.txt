BOT DE PAQUETES - como la primera version
==========================================

1. Instalar Python (python.org). En el instalador marcar "Add Python to PATH".
2. Abrir SGA e iniciar sesion ahi. El bot no pide sesion de Witlink.
3. Abrir token.txt, pegar el token (Programacion -> Bots -> Generar token del bot) y guardar.
4. Doble clic en ejecutar_bot.bat

Witlink entrega las atendidas sin paquete de ayer y de hoy. El paquete vuelve solo.
